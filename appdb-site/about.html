ABOUT THE PROJECT

A clean-room
shortcut.

PocketHLE does not emulate a whole Windows CE device. It loads the real game PE, executes its ARM or MIPS code, and services imported system calls with host-side Rust.

ARCHITECTURE

The game stays real.
The operating system gets focused.

01PE loaderMaps the original executable and resolves imports.
02CPU backendRuns guest ARM or MIPS instructions through Unicorn.
03HLE API layerReimplements coredll, GAPI, GLES, audio, files, and more.
04FrontendPresents frames and input on CLI, desktop, or Android.
