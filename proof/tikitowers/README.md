# Tiki Towers proof

This directory contains the checked-in Tiki Towers capture from PocketHLE.

- `file frames/frame_000000.jpg` — 720×840 captured frame showing the in-game `ENABLE SOUNDS?` prompt with the green confirm and red cancel icons.
- `run.log` — provenance and verification notes for this capture.

The evidence confirms that Tiki Towers boots and renders its sound-selection screen in PocketHLE. It does not claim verified tap or drag gameplay because the original capture has no raw input-event trace.

The source screenshot was committed as `file proof/Screenshot_20260805-223047_PocketHLE.jpg` in commit `b521601`.
