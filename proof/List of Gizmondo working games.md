# List of Gizmondo working games

Verified with PocketHLE's ARM Unicorn backend on the Gizmondo 320×240 landscape layout. These are emulator-side compatibility results, not tests on original hardware.

| Game | Result | Proof |
| --- | --- | --- |
| Agaju — The Sacred Path of Treasure | Launches to the populated main menu; clean exit | [`agaju-windows-mobile/`](agaju-windows-mobile/) |
| Alien Hominid | Reaches rendered gameplay; clean exit after 200 captured frames | [`alien-hominid-gizmondo/`](alien-hominid-gizmondo/) |
| Ball Busters | Reaches menus, character selection and an Arcade match; clean exit after 3000 captured frames | [`ball-busters-gizmondo/`](ball-busters-gizmondo/) |

## Notes

- Gizmondo card images are detected automatically and use the console's 320×240 landscape display.
- The list records the deepest verified state for each title. It does not claim that every mode or the entire game is playable.
- Game archives and copyrighted game data are not included in this repository.
